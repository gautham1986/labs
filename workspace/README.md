# workspace/

Everything **you** produce lives here, so it is easy to edit from your host editor and
easy to back up. It is git-ignored.

```
workspace/
├── answers/      # answer files for system labs, e.g. answers/b01-secret.txt  (also ~/answers)
├── scripting/    # your scripts for the shell scripting track, e.g. scripting/s01/greet.sh
├── notes/        # your own notes - copy templates/learning-log.md here
└── .state/       # progress tracking used by `lab list` / `lab progress`
```
